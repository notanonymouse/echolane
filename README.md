# 🧠 EchoLane

> A deeply empathetic, minimalist digital orientation dashboard and AI voice anchor designed to ease morning anxiety and "sundowning" confusion for early-stage dementia patients.

---

## 🌟 The Problem
Dementia and early-stage Alzheimer's patients frequently experience intense disorientation upon waking up (frequently asking *What day is it? Am I safe? Is anyone coming today?*). This repetitive anxiety places an immense emotional burden on family caregivers who must constantly reassure them. 

## ✨ Our Solution
**EchoLane** acts as a standalone, zero-friction smart tablet dashboard mounted at the patient’s bedside. It anchors them to reality using high-contrast typography, assistive audio feedback, and direct remote updates from loved ones.

### 🚀 Key Features
* **Daily Anchor Display:** Dynamically updates the day name, time period (Morning/Evening), date, and local ambient weather conditions.
* **Caregiver Portal Simulator:** A hidden administration panel allowing family members to securely update the bedside message from anywhere in the world instantly.
* **Low-Friction Audio Engine:** Built using Web Speech synthesis, tapping *anywhere* on the screen beautifully dictates the entire dashboard state aloud in a calmed, adjusted pace.
* **Medication Check-In:** A secure micro-utility that allows patients to confirm their daily doses with local storage tracking.
* **One-Touch Crisis Dial:** Built-in mobile anchor allowing the patient to rapidly trigger a phone call to their designated guardian if they feel unsafe.

## 🛠️ Tech Stack
* **Framework:** React 18 + Vite
* **Styling:** Tailwind CSS (Custom Dark Midnight Gradient Aesthetic)
* **API/Engines:** Web Speech Synthesis API
